About Dr. PROBEN

The Tool

Dr. PROBEN is a medical problem classifier web app based on a Feed-forward Neural Network model integrated with the Multiple Hybrid Ant Colony Optimization for Continuous Domain (ACOR) and Levenberg-Marquardt (LM) algorithm. The application was designed to guide healthcare professionals in diagnosing medical conditions such as Diabetes, Heart Disease, and Breast Cancer.

The Dataset

The app's model was trained on the PROBEN1 benchmark set, which is a collection of problems for neural network learning in the realm of pattern classification and function approximation, plus a set of rules and conventions for carrying out benchmark tests. PROBEN1 contains 15 data sets from 12 different domains. Three datasets involve diagnosis tasks whose data were donated by hospitals and established institutions.

Hybrid ACOR-LM Model

Runs on a feed-forward neural network trained with the hybrid algorithm of ACOR for global search and LM for local fine-tuning. The result is a model with faster convergence and higher accuracy.

Single & Batch Prediction

Designed for clinical flexibility, supporting two distinct input modes: Single-Patient interface for real-time manual entry, and Batch CSV Processing for analyzing large datasets of patient records simultaneously.

Benchmarked Performance

System reliability was validated against the PROBEN1 Benchmark Collection. The model has been rigorously tested on standard medical datasets to ensure high classification accuracy and reproducibility.
